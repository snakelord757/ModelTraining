Пикник v2

Запуск повторного цикла: .\start-picnic-v2.ps1
Включает новые контексты, 32 ответа базовой модели, 32 ответа адаптера v1,
обучение нового адаптера с нуля и 32 ответа v2. Не перезаписывает существующие адаптеры.

Общение после завершения:
  .\ask-picnic-v2.ps1
  .\ask-picnic-v2.ps1 -Base
  .\ask-picnic-v2.ps1 -Previous
Выход: /exit. Все три режима используют один новый поиск и системный запрос.

Поиск: multilingual-e5-small, revision 614241f622f53c4eeff9890bdc4f31cfecc418b3.
Карточка модели: https://huggingface.co/intfloat/multilingual-e5-small
Применены query:/passage: префиксы, усреднение с attention mask и нормализация.
Энкодер работает на CPU; индекс — только текст пользовательского PDF, без карточек ответов.
Окна 160 слов с шагом 110, HTML entities декодированы; 488 фрагментов.
Гибридный поиск: dense + BM25, reciprocal rank fusion 0.7/0.3, k=30,
до 6 фрагментов и до 2 на страницу. Вес — не вероятность правильного ответа.
Номера страниц — порядковые номера страниц PDF.

Датасет: data/picnic-grounded-v2, 170 train / 53 validation / 18 прежних test.
Дубликаты с отвлекающим контекстом — вариации, не новые независимые факты.
Негативные примеры спрашивают отсутствующие во фрагментах даты, числа и идентификаторы.
Сохранено разделение по темам. Вопрос о корабле пересекается с train и отмечен диагностическим.
В новом сравнении 20 прежних заданий + 12 новых формулировок на прежних удержанных темах.
Последние 12 не являются независимым тестом новых тем и тоже требуют проверки по источнику.

Обучение: исходная Qwen3-1.7B, QLoRA r8, 4 эпохи, LR 5e-5, максимум 4096 токенов.
Выбор checkpoint — только validation loss. Loss считается только по ответам.
Поиск, промпт и параметры генерации одинаковы для всех трёх моделей.
По сравнению с прошлым архивным прогоном одновременно изменились поиск и промпт;
поэтому разницу архивного и нового ответа нельзя приписывать только поиску.
Эффект самого обучения v2 оценивается относительно базы и v1 внутри нового отчёта.

Статус: pipeline-status.json. Итоговый адаптер и отчёт: picnic-v2.json.
Отчёт включает время обучения, тексты, общий контекст и автоматические сигналы ошибок.
Автоматические сигналы не заменяют смысловую проверку и не доказывают отсутствие выдумок.
