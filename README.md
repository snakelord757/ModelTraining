# ModelTraining

Локальные эксперименты QLoRA с Qwen3-1.7B на RTX 5060 Ti 16 ГБ:
обучение, поиск по пользовательскому PDF и сравнение ответов до/после.

## Запуск

Окружение: Windows PowerShell, WSL `GemmaTraining`, Python
`/home/trainer/gemma-qlora/.venv/bin/python`. Пути запуска привязаны к
`D:\ModelTraining`; при переносе их необходимо адаптировать.

- [Настройка окружения](TRAINING-ENVIRONMENT.txt)
- [Зафиксированные зависимости](requirements-resolved.txt)
- [Основной сценарий обучения](TRAINING-USAGE.txt)
- [Справочник v1](PICNIC-README.txt)
- [Гибридный поиск и эксперимент v2](PICNIC-V2-README.txt)

```powershell
.\start-picnic-v2.ps1
.\ask-picnic-v2.ps1
# Базовая модель с тем же гибридным поиском:
.\ask-picnic-v2.ps1 -Base
```

Нужны отдельно загруженные модели в `models/`, подготовленные токенизированные
данные и локальное окружение. В репозитории находятся скрипты скачивания и
подготовки; веса и виртуальные окружения в Git не включены. Скрипты обучения
отказываются перезаписывать непустую директорию результатов.

## Отчёты

Вся папка `reports/`, включая HTML, ответы JSON, контексты, разборы и логи,
находится под контролем версий.

- [Первый grounded-эксперимент](reports/20261028T175529Z-picnic/report.html)
- [Сравнение базы, адаптера v1 и v2](reports/20261028T181312Z-picnic-v2/report.html)

В v2 поиск улучшился, однако новый адаптер не рекомендован как замена по
умолчанию: содержательная проверка обнаружила уверенные ошибочные ответы.
Снижение validation loss не является доказательством фактической точности.

## Данные и хранение

Версионируются подготовленные текстовые наборы `data/picnic-pdf-reference-v1/`,
`data/picnic-grounded-v2/` и индекс `data/picnic-search-v2/`. Источник — PDF,
предоставленный пользователем; происхождение и хеш записаны в манифестах.
Права на исходное произведение принадлежат правообладателям; открытая лицензия
на текст книги этим репозиторием не предоставляется.

В Git не включены большие литературные корпуса, Arrow-кеши, веса, адаптеры,
checkpoint-файлы, WSL-диски, окружения и изменяемые локальные статус-файлы.
Они остаются на локальном диске. Исторические скрипты и отчёты сохранены;
актуальные команды для эксперимента v2 приведены выше.
